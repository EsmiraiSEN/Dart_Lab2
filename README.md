# **Lab2 Todo — консольное ToDo-приложение на Dart**

Учебный проект по лабораторной работе №2: классы и объекты в Dart.
Консольное приложение для управления списком задач, написанное на языке Dart с использованием объектно-ориентированного подхода.

## **Запуск**
1. Клонировать репозиторий: `git clone <url>`
2. Перейти в папку: `cd lab2_todo`
3. Установить зависимости: `dart pub get`
4. Запустить: `dart run`

## **Управление (команды)**
После запуска приложения вводите команды в консоль:

1. `add` — добавить новую задачу;

2. `list` — показать все задачи;

3. `done` — отметить задачу выполненной (нужно ввести ID);

4. `delete` — удалить задачу (нужно ввести ID);

5. `exit` — выйти из приложения.

## **Ответы на контрольные вопросы**
1. **В чём разница между полем класса и обычной переменной в функции?**
Поле класса принадлежит объекту (или самому классу, если оно статическое) и существует на протяжении всей жизни объекта. К нему можно обращаться из любых методов этого класса. Обычная переменная внутри функции является локальной: она создается при вызове функции и уничтожается сразу после выхода из нее, к ней нельзя обратиться извне.

2. **Что такое конструктор и зачем он нужен?**
Конструктор — это специальный метод класса, который автоматически вызывается при создании нового экземпляра (объекта). Он нужен для инициализации полей объекта, чтобы гарантировать, что объект создается в корректном, рабочем состоянии (например, чтобы поля не оставались пустыми или null).**

3. **Зачем нужен @override перед toString()? Что будет если его убрать?**
@override — это аннотация, которая сообщает компилятору, что данный метод переопределяет метод из родительского класса (в данном случае из базового класса Object). Если её убрать, программа продолжит работать, но компилятор не будет проверять правильность сигнатуры. В случае опечатки в названии метода (например, toStrng), компилятор не выдаст ошибку, и вы просто создадите новый метод вместо переопределения существующего, что приведет к некорректной работе программы.

4. **Чем статическое поле static int _counter отличается от обычного поля? Сколько копий этого поля существует в программе?**
Обычное поле (например, id или title) существует в единственном экземпляре для каждого созданного объекта (у 10 задач будет 10 разных полей id). Статическое поле принадлежит самому классу. В программе существует всего одна копия этого поля, независимо от того, сколько объектов класса Todo было создано. Все объекты используют это поле совместно.

5. **Что означает нижнее подчёркивание в _counter?**
В языке Dart нижнее подчёркивание в начале имени идентификатора делает его приватным (закрытым) на уровне библиотеки (файла). Это значит, что к переменной _counter можно обратиться только из того же файла (lib/todo.dart), где она объявлена. Из других файлов (например, из main) доступ к ней будет закрыт.
